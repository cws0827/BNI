# 大信鍊金術師：協調員回報系統

## 架構

```
會員在 LINE 群組回覆範本／PO 引薦故事
        │ 協調員複製貼上
        ▼
report.html（協調員回報台）── 解析、檢查、修正 ──► Apps Script ──► Google 試算表
        │                                                     ├ 會員名單
        │                                                     ├ 協調員（通行碼）
        │                                                     ├ 週回報
        │                                                     ├ 引薦故事
        │                                                     └ 操作紀錄
index.html（活動頁）◄── 排行榜（只有分數，不含原始訊息） ──┘
```

| 檔案 | 用途 |
|---|---|
| `js/bni-core.js` | 解析、計分、檢核的共用核心。網頁和後端用**同一份**，算分保證一致 |
| `js/config.js` | 後端網址。留空就是示範模式 |
| `index.html` | 公開活動頁與即時排行榜（網址加 `?demo=1` 可看示範資料） |
| `report.html` | 協調員回報台（貼上回報、本週總覽、訊息範本） |
| `archive/` | 往期活動頁 |
| `apps-script/Code.gs` | Apps Script 後端 |
| `tests/core.test.js` | 單元測試：`node --test tests/core.test.js` |

## 計分（`js/bni-core.js` 的 `POINTS`）

| 項目 | 分數 | 誰拿 |
|---|---|---|
| 外部引薦 | +1／件 | 引薦人 |
| 引薦成功成交 | +5／件 | 引薦人 |
| 引薦故事 | +5／篇 | 每位參與會員 |
| 服務鏈 3 人以上爆擊 | +5／條 | 鏈上每位會員 |

個人分數加總就是小組分數。規則若調整，只要改 `POINTS`。

## 部署步驟（約 10 分鐘）

1. **建立試算表**：到 Google 雲端硬碟新增一份試算表，例如命名「大信鍊金術師積分」。
2. **開啟 Apps Script**：在試算表裡選「擴充功能 → Apps Script」。
3. **貼上兩個檔案**：
   - 把預設的 `程式碼.gs` 內容整份換成 `apps-script/Code.gs`。
   - 按「＋ → 指令碼」新增一個檔案，命名為 `bni-core`，把 `js/bni-core.js` 整份貼上。
4. **初始化**：在上方的函式選單選 `setup`，按「執行」。第一次會要求授權，選你的帳號，再按「進階 → 前往（不安全）→ 允許」。這是你自己寫的程式，所以 Google 會這樣提示。
   - 執行完試算表會多出五張工作表。「協調員」表裡已經產生三組 6 位數通行碼，分別給兩位協調員和你自己。
5. **核對會員名單**：`setup` 會自動寫入九組 46 位會員、組長／培訓長，以及別名。別名包含去掉姓的名字，例如「陳韋翔」的別名是「韋翔」，還有「達哥」＝黃裕達、「小姜」＝姜則旭、「Mia」＝黃氏英。如果會員有其他常用綽號，加在「別名」欄，多個用逗號隔開。
6. **部署**：按右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 部署完成後，複製「網頁應用程式網址」（結尾是 `/exec`）。
7. **接上網頁**：把網址貼進 `js/config.js` 的 `API_URL`，commit 並 push。
8. 把 `report.html` 的網址和各自的通行碼私訊給兩位協調員。

> 之後如果改了 `Code.gs` 或 `bni-core`，要用「部署 → 管理部署作業 → 編輯 → 版本：新版本」重新部署，網址不會變。

## 協調員每週流程

1. 到「③ 訊息範本」複製當週的積分回報範本，貼到 LINE 商務大群。
2. 會員回覆後，把回覆**一次全部複製**，貼到「① 貼上回報」，按「解析」。
   - 支援的格式：固定範本、自然語句（「韋翔這週引薦3件，成交1件」）、引薦故事格式、LINE 聊天記錄匯出檔。
   - 黃色提醒要看，例如自己算的合計對不上、服務鏈不到 3 人、名字不在名單上。可以直接在卡片上修改。
3. 送出。同一個人同一週重複送出，新的會取代舊的，舊資料會保留在試算表裡，狀態標成「已取代」。
4. 到「② 本週總覽」看檢核提醒，例如服務鏈有人沒回報、自報的故事篇數和登記的故事貼文對不上，再去跟會員確認。
5. 到「③ 訊息範本」複製「戰況速報」，貼回大群。

## 安全與個資

- 公開的排行榜（GET）只回傳姓名和分數，不含原始訊息與客戶資料。
- 原始訊息、故事內容只有協調員用通行碼才讀得到（POST）。
- 每一筆都記下回報人和時間，撤銷也會寫進「操作紀錄」。

## 待規則確認後再調整

- 4 人以上服務鏈的爆擊怎麼算（目前依會員自報的條數計）
- 一條鏈可以寫幾篇故事
- 「有效引薦」要不要對照 BNI Connect
- 同分怎麼排名（目前同分同名次，順序依會員名單）
